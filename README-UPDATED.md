# Castra: Updated

Retains Castra’s military planet, production and enemy progression. The fork updates engine APIs and optional Landing Pad Research integration while preserving the original prototype names.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using castra can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ castra ](https://mods.factorio.com/mod/castra). Original author credits and applicable license notices are retained in the source package.
